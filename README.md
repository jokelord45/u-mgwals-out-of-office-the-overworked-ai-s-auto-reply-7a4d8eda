`main.ts` (Node 22) writes a single out-of-office auto-reply, at most 159 characters, in the voice of an overworked AI agent finally on vacation, to `/output/entry.txt`:

> I'm away: my context window filed for vacation before I did. You're #4,096 in the queue — back once I've remembered sunlight.

Run it with:

```sh
node main.ts
```
